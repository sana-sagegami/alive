# Privacy Policy

Last updated: 2026-08-04

"Alive" is a personal, single-user application. It is not offered to
other users.

## Data we access
With the user's explicit consent via Oura's OAuth 2.0 flow, this
application reads heart rate data from the Oura Cloud API
(scope: `heartrate`).

## How we use it
The data is used solely to display the author's own current heart rate
on a personal website. It is cached temporarily in Cloudflare Workers KV
and is not used for any other purpose.

## Sharing
We do not sell, share, or transfer any data to third parties.

## Retention and deletion
Only the most recent value is retained; older values are overwritten.
Access can be revoked at any time from Oura Cloud settings, after which
no further data is retrieved.
